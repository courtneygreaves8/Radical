# Radical Church UK

Loud Swiss × brutalist marketing site for [Radical Church](https://www.radicalchurchuk.com) — built by [Babe / beblessed.io](https://beblessed.io).

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4 + shadcn/ui
- React Router 7 + Framer Motion
- Sanity-ready (`src/lib/sanity`) with local seed content until a project ID is set

## Develop

```bash
npm install
npm run dev
```

## Env

Copy `.env.example` → `.env` and add `VITE_SANITY_PROJECT_ID` when the studio is live.
